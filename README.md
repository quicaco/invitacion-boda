# Invitación · Marta & Víctor

Web de invitación para la boda de Marta y Víctor (23 de octubre de 2027).
Se publica con GitHub Pages desde la rama `main`.

- `index.html`: la invitación completa (HTML, CSS y JS en un solo archivo).
